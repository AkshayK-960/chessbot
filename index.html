How it Works

For this project, I used chessboard.js to display the board, and FastBitboardEngine to generate all the possible moves including castling, en passant, etc.

This program makes the best moves using a custom-made FEN evaluation algorithm. It parses the FEN string into an 8x8 grid using a for loop, and then runs it through all possible moves...

Note: However, I ran into an error. Since it only searches one depth deep it moved the knight out and kept moving the rook back and forth, and only captured when it needed to.
