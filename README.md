# Minimax Chess Bot
A browser based chess bot that uses piece square tables, transposition tables, minimax, alpha-beta pruning and zobrist hashing techniques to play both with the black and white pieces.
*(Note: add gif/image of game)

## How to Play
To play against this chess bot, you can head over to the [Releases page](https://github.com/AkshayK-960/chessbot/releases/), download the files, and run the index.html file.

## Features
This chess bot has many optimization methods, and these help it perform better, inclding:
* Minimax algorithm
* Alpha-Beta Pruning
* Zobrist Hashing
* Move Depth implementation
